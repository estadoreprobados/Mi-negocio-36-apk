FASE 10.3 — Mi Primer Negocio 3.10.0 (compilación 34)

- Se sincroniza versionName/versionCode de Android con la pantalla «Versión del sistema» y APP_VERSION.
- Se actualiza el nombre visible de la aplicación a «Mi Primer Negocio», sin cambiar applicationId ni namespace.
- Se incorpora generación local de códigos de barras Code 39 en el formulario de productos.
- Se añade vista previa imprimible del código y se muestra el código asociado en tarjetas y tabla de inventario.
- Se impide guardar un código duplicado en dos productos distintos.
- Los códigos existentes se conservan; no se modifica la clave localStorage mpn36_v2_data ni el formato de respaldo.

Nota: Code 39 admite letras mayúsculas, números, espacios y los caracteres - . $ / + %. La lectura depende de que el lector utilizado admita Code 39.
