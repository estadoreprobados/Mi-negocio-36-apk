Mi Primer Negocio 36 — versión 3.7.2

Este ZIP contiene el código fuente actualizado. No es un APK instalado ni una prueba de que la compilación ya haya terminado.

1. Haz una copia del repositorio y exporta un respaldo JSON desde la app.
2. Sube el contenido manteniendo las rutas del ZIP.
3. Comprueba que se actualicen las copias Android dentro de app/src/main/assets/. El WebView carga esos archivos.
4. Abre GitHub Actions y espera a que la compilación termine correctamente.
5. Descarga el APK de esa ejecución e instálalo sin borrar los datos anteriores.
6. En Menú → Versión del sistema verifica versión 3.7.2 y compilación 19.
7. Prueba la mascota, empleados, PDF, ventas e inventario.

Manolito es una mascota con consejos predeterminados, sin IA. El botón «Dame un consejo» utiliza información local para sugerir revisar inventario, registrar ventas o completar los registros.

Antes de reemplazar archivos, conserva una copia del repositorio. No desinstales la app ni borres sus datos sin comprobar que tienes un respaldo JSON válido.

Consulta CAMBIOS_VERSION_3.7.2.txt y README.md para la lista detallada de novedades, ajustes y limitaciones.
