# Mi Primer Negocio 36 — v3.7.01

Aplicación para llevar control local de productos, inventario, ventas, gastos y operaciones de un pequeño negocio.

## Novedades de v3.7.01
- Nuevo apartado Empleados y mano de obra: nombre, puesto, pago por hora, horas normales, horas extras y estimación del pago bruto.
- El reporte PDF incluye secciones detalladas de inventario, ventas, gastos, empleados, clientes, proveedores, compras, notas, movimientos de inventario, movimientos de crédito y cortes de caja, con los datos disponibles.
- Temas Cyberpunk y Galaxia con paletas específicas para modo claro.
- La pantalla Versión del sistema muestra las novedades de esta actualización.

## Datos y privacidad
Los datos se almacenan localmente en el dispositivo. Exporta un respaldo JSON antes de reinstalar, borrar datos o cambiar de dispositivo. El PDF es un reporte de consulta; no sustituye un respaldo restaurable.

## Notas importantes
Los cálculos de mano de obra son estimaciones. La nómina y las horas extras deben verificarse conforme a la legislación aplicable. Las funciones deben probarse en el dispositivo antes de distribuir la compilación.
